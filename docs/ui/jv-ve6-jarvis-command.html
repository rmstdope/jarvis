Option A — every doctor state gets its own exact fix line

The doctor line chosen in round 1 (a warning), walked through every state it can be in. Highlighted lines are new.

1 · Installed and working

✓ jarvis-command     jarvis on PATH

2 · Never installed

⚠ jarvis-command     jarvis is not on PATH, so agents in the content repo cannot run it
    fix: cd /Users/you/repos/jarvis && bun link

3 · Installed, but bun's install folder is not on PATH (common on a fresh machine)

⚠ jarvis-command     jarvis is installed in ~/.bun/bin, but that folder is not on PATH
    fix: echo 'export PATH="$HOME/.bun/bin:$PATH"' >> ~/.zshrc   then open a new terminal
     (the fix names the user's own shell file: ~/.zshrc, ~/.bashrc, or the fish equivalent)

4 · Installed from a different copy of the code (an old clone)

⚠ jarvis-command     jarvis on PATH runs /Users/you/old/jarvis, not /Users/you/repos/jarvis
    fix: cd /Users/you/repos/jarvis && bun link

cd <content-repo>
copilot            # or: claude, or your agent of choice
