jv-z1g — linking an initiative to one of its own tasks

Same words as moving a task into the initiative it is already in. Nothing is written, so nothing can hide. The same answer for every relation (--relation contradicts etc.), either way round, CLI and web chat alike. It is not a failure. Links made this way before today are left as they are.

The case

$ jarvis link 01JD4K7M 01JD4M2X
01JD4M2X  Export last year's invoices  is already a task in Move billing to the new ledger — nothing linked

Either way round

$ jarvis link 01JD4M2X 01JD4K7M
01JD4M2X  Export last year's invoices  is already a task in Move billing to the new ledger — nothing linked

Several at once — each says its own line

$ jarvis link 01JD4K7M 01JD4M2X,01JC77AB
01JD4M2X  Export last year's invoices  is already a task in Move billing to the new ledger — nothing linked
linked: 01JD4K7M → 01JC77AB [references]

A task of a different initiative — unchanged, it links and shows under "linked directly"

$ jarvis link 01JD4K7M 01JDX900
linked: 01JD4K7M → 01JDX900 [references]
