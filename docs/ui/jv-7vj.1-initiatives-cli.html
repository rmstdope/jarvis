Create

$ jarvis initiative add "Move billing to the new ledger" --goal "All invoices issued from the new ledger by March" [--owner anna]
initiative 01JD4K7M  Move billing to the new ledger  (owner anna)

Owner defaults to you, as for tasks.

$ jarvis initiative add "Move billing to the new ledger"

  jarvis initiative add "Move billing to the new ledger" --goal "<what done looks like>"
